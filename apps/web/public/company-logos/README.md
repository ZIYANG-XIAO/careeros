# Company logos

This directory contains locally bundled website icons for every employer in the
current Greenhouse, Lever, and Ashby source catalogs. The corresponding official
website domains are recorded in `catalog.json`.

The images are used only to identify their respective companies. Trademarks and
artwork remain the property of their owners. Runtime UI rendering is same-origin
and does not disclose a user's job browsing to a third-party logo service.
